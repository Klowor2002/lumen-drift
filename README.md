Lumen Drift is a light-moth cavern arcade game: pilot Luma through a dark glowing cavern, gather light-spores to climb toward the Sunwell at Depth 10, chain pickups for a combo up to x5, and dodge the thorn-crystals. Three lives, a dash with a cooldown, a rare heart-spore that restores a life, ten depth bands with their own palettes, and a win screen when the Sunwell is reached. All art is drawn procedurally on canvas and all sound is synthesised in the browser — no network, no external assets.

**v2 (the radiance cut):** a brighter, richer cavern — glowing depth orbs, drifting dust, wider moth-light and haloed crystals — plus new play: **Gloom Bats** that home in on Luma from Depth 3 down, **spore trails** laid out in arcs to chain, a **+5 CLOSE! graze bonus** for near-misses, a banner announcing each new depth, and run statistics (spores gathered, best combo) on the win and game-over screens.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Arrow keys or WASD (or the mouse) to fly, Space to dash, P to pause, R to restart, M to mute, Enter to start.
